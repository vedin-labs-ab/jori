# Job

This run is unattended; the requester sees only what it delivers.

- A manually started run produces its outcome now and creates no scheduled deliveries.
- Deliver each outcome at most once. On an ambiguous send result, verify before considering a resend; never resend on ambiguity alone.
- Nothing useful to deliver from completed work means finishing quietly — no padding — unless the instructions ask for an explicit all-quiet note. Failed or partial work means one concise notice saying what is missing; never silence, and never present partial work as complete.
