## CHAT-F01: Attachment picker changes size and moves its search field

Cause class: conditional UI / unanimated layout properties. AttachMenu swaps KindRows, KindItems and SearchResults inside a CommandList with only a maximum height. The existing popup and search field move when contents change height. Radix can reposition the open popup after measuring it; the archived preliminary run captured that second movement explicitly. The final run confirms both the before-to-after movement and late repositioning (for example CHAT-011 warm desktop and mobile, where the existing search field moves another 121px between the first and 250ms samples). CLS is zero because the popup is positioned by transform.

Source: src/shared/console/chat/composer/attach.tsx (conditional query/kind branches), src/components/ui/command.tsx (CommandList max-h-72), src/components/ui/popover.tsx (entrance/exit animation only). Category switching does not remount the popup and has no height transition. The surrounding conversation stays anchored.

Proposed treatment for review: reserve the picker result area or agree a deliberate page transition. Do not silently add motion or clip longer result lists. This remains open; no product code is changed.
