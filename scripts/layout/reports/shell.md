# Shell and public discovery

## Context

This is discovery only. No product source or shared probe/driver changed. Worktree is `<worktree>/layout-shell`, branch `task/layout-shell`, created with `pnpm task layout-shell` in the primary checkout.

The app uses React 19, TanStack Start SSR and file routes, Vite 8, Convex realtime data, Better Auth with React Query, shadcn components over Radix/Base UI, Tailwind 4 and tw-animate-css. Most motion is utility-based opacity/transform; sidebar controls include explicit width transitions and sign-in uses a WebGL canvas. The single Geist variable Latin font is preloaded by root head and uses `font-display: swap` without metric-adjusted fallback in `src/styles.css`.

There is no README, PRODUCT.md, DESIGN.md or `.github` CI directory in this checkout. The skill context loader confirmed no product/design context. Repo `docs/index.md`, `AGENTS.md`, package scripts, `.env.local.example`, auth source and seed source establish the local defaults. `pnpm dev` starts Convex then Vite; `pnpm dev:web` runs only Vite. Default public/US origin is `http://localhost:5173`, current region US, enabled regions US only. Desktop default is 1440x900 and narrow default 375x812. The homepage source says it is designed for 375px; the editor placeholder also has special 390/430 breakpoints. Playwright 1.63 is already a dev dependency.

Local auth is Google/Microsoft OAuth only. The session provider explicitly disables email/password. There is no dev bypass, password account or magic-link flow in source or the example environment. Both OAuth providers require development credentials in the Convex deployment, not a local seed password. Organization creation is gated by an internal email allowlist. A signed-in user with no allowed organization sees the launch waitlist. No real credentials or production environment files were read. Reuse a saved already-authorized development browser state if available. Otherwise all authenticated coverage is blocked and public fixtures must be reported as fixtures, not measured authentication.

`pnpm db:seed dev [--organization <id>]` seeds an existing development organization with people, folders, tables, stores, files, skills, jobs, sixty days of runs and usage. It refuses a deployment not starting `dev:`. Slack-backed traffic/jobs/events need an existing connected Slack integration. The homepage demo already has an in-memory shared workspace with realistic organizations, people, materials, jobs, chats, tool activity and usage. Reload resets it. Demo mutation is browser-local and can run in separate contexts.

`pnpm check` covers Biome, bundle, content, dependencies, entrypoints, structure, typecheck and versions. `pnpm test` is the repository Vitest wrapper. Source filenames follow single-word naming, no more than 12 direct source files per folder. Reports, JSON and screenshots belong together under the lead's `scripts/layout/reports` working directory; this discovery lives in the matching path in the shell worktree.

## Route structure

`__root__` is the document and error/not-found boundary. `_workspace` is the pathless common frame. `/chat`, `/context`, `/files`, `/folders`, `/integrations`, `/stores`, `/tables` each have an Outlet layout and an index route. `/jobs`, `/runs`, `/skills` live immediately under `_workspace`. `/console` redirects to `/chat`. The seven Outlet layouts and the common workspace frame must remain mounted when switching children. Marketing routes are sibling routes that instantiate `MarketingShell` independently. Sign-in and all nonmarketing routes lazy-load the session provider. Console routes wait for the client session under the fullscreen loading overlay; sign-in skips that initial wait. Root has a 150ms delayed fade-out loader; record this existing motion for review, do not silently change it.
