# Triggers

## Responsibility

Owns activation conditions for work, routines, agent runs, reviews, and suggestions.

## Owns

- Manual triggers: direct user requests and commands.
- Scheduled triggers: time-based activation.
- Event triggers: activation from observed activity.
- State triggers: activation from work or memory state changes.
- Routines: repeatable trigger-and-action patterns.

## Boundary

Agent reasoning belongs to [Agents](../agents/README.md). Concrete action belongs to [Execution](../execution/README.md).
