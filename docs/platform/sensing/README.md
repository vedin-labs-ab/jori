# Sensing

## Responsibility

Owns raw intake before it becomes memory, work, triggers, or agent context.

## Owns

- Sources: where observed information comes from.
- Events: changes, signals, and activity records.
- Artifacts: files, documents, code, notes, and other source material.
- Messages: conversational inputs from chat, email, comments, and threads.
- Meetings: live or recorded company conversations.
- Imports: deliberate uploads or migrations into Milo.

## Boundary

Durable interpretation belongs to [Memory](../memory/README.md).
