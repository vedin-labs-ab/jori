# Integrations

## Responsibility

Owns external tool relationships and the capabilities Milo can use through them.

## Owns

- Connected tools: products and systems linked to Milo.
- Accounts: authorized identities and installation contexts.
- Capabilities: what Milo can read, search, create, update, or execute.
- Scopes: explicit external permission boundaries.
- External objects: references to tool-native records and artifacts.

## Boundary

Activation belongs to [Triggers](../triggers/README.md). Concrete action belongs to [Execution](../execution/README.md).
