# Workflows

## Responsibility

Owns repeatable paths from trigger to outcome: activation, routing, state, review, approval, handoff, and completion.

## Owns

- [Triggers](./triggers/index.md)
- [Routines](./routines.md)
- [Reviews](./reviews.md)
- [Handoffs](./handoffs.md)

## Boundary

Work intent belongs to [Work](../work/index.md). Agent reasoning and execution belong to [Agency](../agency/index.md). Governance defines what workflows are allowed to do.
