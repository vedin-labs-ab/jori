# Triggers

## Responsibility

Owns the conditions that start requests, tasks, routines, reviews, or agent runs.

## Includes

- Manual triggers from explicit user commands.
- Scheduled triggers from time-based routines.
- Signal triggers from messages, meetings, imports, and integration events.
- State triggers from changes to work, memory, identity, permissions, or prior runs.

## Boundary

Observed activity belongs to [Context](../context/index.md). Triggered attempts belong to [Runs](./index.md).
