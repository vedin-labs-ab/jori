# Control

## Responsibility

Owns approval, auditability, access enforcement, policies, and trust boundaries.

## Owns

- Approvals: explicit human permission to proceed.
- Audit history: understandable records of what happened.
- Access control: enforcement of visibility and action boundaries.
- Policies: company rules that constrain system behavior.
- Trust levels: how much autonomy Milo has in each context.
