# Platform

Milo's platform is the runtime model behind the companyOS.

## Responsibility

Defines the domains that let people trigger agents, run work in the cloud, use tools safely, remember what happened, and improve future agent behavior.

## Runtime Loop

A person, system, schedule, or signal triggers a request, task, or run. An agent plans and acts with tools, models, integrations, and sandboxes. The run produces artifacts, review points, and traces. Context and memory update from those traces. Dreaming studies company activity and prior runs to improve skills and future delegation.
