# Platform

Milo's platform is the companyOS domain model.

## Responsibility

Defines the durable mental model for company context, work, workflows, agents, governance, and the human surfaces that keep Milo accountable.

## Operating Loop

Milo observes company activity, turns useful signal into memory, connects that memory to work, activates workflows, delegates execution to agents, routes review back to people when needed, and records what happened.
