# Agents

## Responsibility

Owns delegated reasoning, planning, tool use, review loops, and outcomes.

## Owns

- Agents: named or configured workers.
- Skills: reusable ways of doing work.
- Delegations: assigned responsibilities from people or systems.
- Plans: proposed paths from request to outcome.
- Tool use: intentional use of integrations, models, and execution environments.
- Reviews: checkpoints before, during, or after agent work.

## Boundary

Permission assignment belongs to [Company](../company/README.md). Policy enforcement belongs to [Control](../control/README.md).
