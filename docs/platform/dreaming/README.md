# Dreaming

## Responsibility

Owns background reflection, opportunity discovery, and prepared suggestions.

## Owns

- Reflection: periodic review of company context and activity.
- Pattern detection: repeated signals across work, tools, and memory.
- Opportunity discovery: places where Milo could help.
- Routine improvement: suggestions for making recurring work better.
- Prepared drafts: proposed work that waits for review or activation.

## Boundary

Activation belongs to [Triggers](../triggers/README.md). Approval belongs to [Control](../control/README.md).
