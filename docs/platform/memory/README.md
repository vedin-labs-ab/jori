# Memory

## Responsibility

Owns durable company context, trust level, and context boundaries.

## Owns

- Knowledge: interpreted company understanding.
- Facts: stable claims Milo can rely on.
- Assumptions: useful but uncertain beliefs.
- Preferences: how people, teams, and the company prefer work to happen.
- Histories: important past activity, decisions, and outcomes.
- Context boundaries: where a memory is valid, visible, and useful.

## Boundary

Raw intake belongs to [Sensing](../sensing/README.md). Activation belongs to [Triggers](../triggers/README.md).
