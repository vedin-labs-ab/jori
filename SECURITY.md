# Security

Report suspected vulnerabilities privately to
[support@usejori.com](mailto:support@usejori.com), with "Security report" in the subject.
Please do not report vulnerabilities in public issues or pull requests.

Include the affected feature or commit, steps to reproduce, and potential impact.
Remove credentials and personal or customer data from any examples or attachments.
Please coordinate public disclosure with us while we investigate and address the issue.
