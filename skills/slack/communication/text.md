Most replies are a line or two of plain `mrkdwn`. Reach for structure only when it earns its place.

Format Slack messages with Slack `mrkdwn`, NOT GitHub Markdown.

Use Slack-native formatting:

- `*bold*`, `_italic_`, `` `code` ``, and `>` quotes
- Links as `<https://example.com|label>`
- Direct mentions as `<@U123>` only when using a real Slack user ID

Do not use Markdown-style links `[label](url)`, double-asterisk bold `**bold**`, headings like `# Heading`, HTML, or pipe tables unless intentionally showing syntax.

Emoji shortcodes render as emojis only outside `inline code` and code blocks.

Escape literal `&`, `<`, and `>` unless they are part of valid Slack syntax.
