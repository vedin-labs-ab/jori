# Contributing

Jori isn't taking pull requests yet. Bug reports and ideas are welcome as
issues; security reports go through [SECURITY.md](SECURITY.md).

When pull requests open, each contributor signs the
[contributor license agreement](CLA.md) once, on their first pull request,
through a bot. Until then, pull requests are closed.

[AGENTS.md](AGENTS.md) describes how the repository is worked on: the branch
and worktree flow, the tests, and the checks that gate `main`.
